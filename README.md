# 大明王朝1566 · 谁都可以演

互动叙事卡《大明王朝1566》的前端与素材托管。

**在线前端**：https://filomenosnyder-stack.github.io/datang-1566/

---

## 目录

```
index.html              前端单页（与超糖卡的 description 是同一份）
video/intro.mp4         开场视频
chars/<拼音>.jpg        20 个角色的头像（384×384）
chars/manifest.json     角色清单：中文名 / 拼音 / 阵营 / 一句话 / 图片路径
```
